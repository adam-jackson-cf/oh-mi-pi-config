# Feature playbook

## Objective

Deliver the requested feature with frozen acceptance evidence.

## Stage deltas

- Frame: define the new user-visible outcome and the affected owners and callers.
- Spike: resolve only remaining questions on the real feature surface.
- Plan: each proof encodes requested behaviour; it fails at base because the feature is absent there.
- Plan: the proof task writes or updates the feature's map entry with each proof.
- Plan: proof tasks freeze runner-invoked journey files and required lever changes together.
- Implement: the implementation task implements the feature within the framed scope.

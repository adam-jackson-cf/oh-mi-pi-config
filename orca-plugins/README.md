# Orca plugins

Styling for the Orca chat and terminal so omp replies
(K/C/S/R/A/F sections, embeds, tool rows) are easier to scan. One layout **mode** and one colour
**palette** drive both surfaces; the `orca-chat-style` skill tells agents how to switch and repair
them.

## Contents

| Folder | What it is | Loaded by |
| --- | --- | --- |
| [`orca-chat-style/`](orca-chat-style/SKILL.md) | Agent skill: environment checks, when to switch modes/palettes, safety rules, chat and terminal references | `install.sh` links it into `~/.omp/agent/skills/` |
| [`chat-section-style/`](chat-section-style/README.md) | The engine: `inject.ts`, chat CSS, palettes, terminal theme generator and assessment harness | `node inject.ts`, then the LaunchAgent every 30 s |
| [`install.sh`](install.sh) | Idempotent setup and repair for this checkout | You or an agent |
| [`catppuccin-sections/`](catppuccin-sections/README.md) | Data-only Orca **app theme** plugin: Catppuccin Latte/Mocha with chat-section token tweaks | `orca plugin dev load` |
| [`terminal-sections/`](terminal-sections/README.md) | Data-only Orca **terminal theme** plugin: Sections Dark/Light, generated by `inject.ts` | `orca plugin dev load` |

```text
mode + palette files (chat-section-style/, machine-local, ignored)
        │
        ▼
inject.ts ──► chat: chat.css + palettes/*.css + id-highlight.js via Orca's inspector
           ──► terminal: terminal-sections/terminal/{dark,light}.json
           ──► omp TUI: ~/.omp/agent/themes/orca-sections-{dark,light}.json
```

Modes: `document`, `split-cards`, `gutter` (default), `editorial`. Palettes: `catppuccin`, `ayu`,
`github`, `vscode`, `auto` (default; follows the selected Orca app theme). Details live in the
[skill](orca-chat-style/SKILL.md).

## Requirements

- macOS with Orca at `/Applications/Orca.app`, its `EnableNodeCliInspectArguments` fuse enabled
  (`npx -y @electron/fuses read --app /Applications/Orca.app`) and inspector port 9229 free.
- Node 22.18 or later on `PATH`: it runs `inject.ts` with built-in type stripping, and `node:sqlite`
  reads Orca's settings read-only.
- omp (optional, for the TUI layer and the skill) using its default agent directory `~/.omp/agent`.
- Harness only: Bun, Google Chrome at `/Applications/Google Chrome.app`, Python 3.
- Palettes other than Catppuccin need the matching Stably theme plugin installed in Orca:
  `stablyai.orca-ayu-theme`, `stablyai.orca-github-vscode-theme` or
  `stablyai.orca-vscode-default-themes`.

## Setup

Start Orca, then from this folder:

```sh
sh install.sh
```

It checks macOS, Orca and Node, then:

1. Runs `node chat-section-style/inject.ts --if-needed`: creates the choice files, generates the
   terminal themes and hooks the open chat.
2. Loads `local.catppuccin-sections` and `local.terminal-sections` with `orca plugin dev load`,
   unless already loaded.
3. If omp is on `PATH`, sets `theme.dark`/`theme.light` to `orca-sections-dark`/`-light` and links
   `orca-chat-style/` into `~/.omp/agent/skills/`.
4. Renders LaunchAgent `local.orca-chat-section-style` from the `node` on `PATH` and this folder's
   real path, writes it to `~/Library/LaunchAgents/` and bootstraps it.
   `sh install.sh --print-launchagent` shows the plist without installing.

Rerun it after moving the checkout or changing Node. Then, in Orca Settings → Appearance, pick the
app themes you want (Catppuccin Sections Latte/Mocha pairs with the `catppuccin` palette) and set
Terminal to **Sections Dark** / **Sections Light**, line height 1.25. Settings stay manual:
nothing here writes Orca's profile database.

## Everyday use

```sh
node chat-section-style/inject.ts --mode editorial --palette auto       # both surfaces
node chat-section-style/inject.ts --surface terminal --palette github   # terminal only
```

A hooked Orca applies chat changes within a second; JSON output reports the applied palette and
any terminal reload error.

## Safety

`inject.ts` opens Orca's main-process inspector for one to two seconds per install. Never patch
`app.asar`, write Orca's profile database, or quit/signal Orca from an agent session running inside
it. Removal and recovery steps are in [`chat-section-style/README.md`](chat-section-style/README.md).
